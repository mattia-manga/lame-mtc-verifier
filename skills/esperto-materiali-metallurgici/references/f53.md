# SA-182 F53 — Super Duplex UNS S32750 / 2507

Designazioni equivalenti: "F53", "UNS S32750", "2507", "Super Duplex" = stesso grado.

Chimica (%): C ≤0.030 · Mn ≤1.20 · P ≤0.035 · S ≤0.020 · Si ≤0.80 · Cr 24.00–26.00 · Ni 6.00–8.00 · Mo 3.00–5.00 · N 0.24–0.32 · Cu ≤0.50

PREN = %Cr + 3.3×%Mo + 16×%N — deve risultare ≥40; ricalcolalo sempre dai valori di colata riportati invece di fidarti di un PREN eventualmente scritto in certificato, e segnala discrepanze.

Meccanica: spessore ≤50 mm: Rm ≥800 MPa (116 ksi), Rp0.2 ≥550 MPa (80 ksi); spessore >50 mm: Rm ≥730 MPa (106 ksi), Rp0.2 ≥515 MPa (75 ksi); A ≥15%; Durezza ≤310 HBW (max). Per servizio sour (NACE MR0175/ISO 15156) spesso richiesto ≤28 HRC: verificare PO.
